RECORDING TIPS
================================================================================
✓ SLOW DOWN - Type slow, click slow, wait 1-2 seconds after each action
✓ SPEAK NATURALLY - Don't sound like a robot, pause between sentences
✓ AUDIO - Clear voice, no background noise, decent mic
✓ SCREEN - Zoom to 125% so text is readable
✓ ZOOM - Don't zoom in/out during video
✓ PRACTICE - Do a test run first
